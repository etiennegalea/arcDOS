# FilDOS review for M6

The review covers FilDOS at [`aa575e8`](https://github.com/ahmedfahim21/FilDOS/commit/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a). The repository is MIT licensed, with copyright © 2026 Fahim Ahmed. Dependency and model licenses are tracked separately from the application license. [FilDOS license](https://github.com/ahmedfahim21/FilDOS/blob/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a/LICENSE)

| Area | FilDOS implementation | ArcDOS design |
| --- | --- | --- |
| Document extraction | Reads text with byte limits, parses PDF pages with pdf.js range reads, and uses Mammoth for DOCX. A watchdog limits extraction time in a separate Electron process. | Read through the confined ArcDOS file service. Give extraction only bounded inputs, keep extracted positions for citations, and validate the source revision before publishing derived records. [Extractor](https://github.com/ahmedfahim21/FilDOS/blob/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a/src/main/ai/index/extract.ts), [extraction watchdog](https://github.com/ahmedfahim21/FilDOS/blob/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a/src/main/ai/index/extractClient.ts) |
| Embeddings | Runs Transformers.js on ONNX Runtime in an Electron utility process, checks and normalizes vectors, and versions the index with model and prompt settings. | Run ONNX inference in an independent worker with operator-provided model files. Identify stored vectors by model and pipeline version so a change can rebuild them. [Embedding runtime](https://github.com/ahmedfahim21/FilDOS/blob/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a/src/main/ai/modelRuntime.ts), [ArcDOS vector storage](vector-index.md) |
| Retrieval | Combines BM25 keyword evidence and vector similarity. Search hits carry passage text and a location within the file. | Keep the existing FTS5 index available during inference outages. Combine it with validated semantic candidates and build citations from the current opaque file IDs and revisions. [Search](https://github.com/ahmedfahim21/FilDOS/blob/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a/src/main/ai/index/search.ts) |
| Chat | Runs one local llama.cpp turn at a time in an Electron utility process and streams token chunks. The Electron main process executes model-invoked file tools. | Stream bounded turns and source references through ArcDOS authorization. Represent any proposed write as data and require an explicit confirmation before the server validates, executes, and audits it. [Chat runtime](https://github.com/ahmedfahim21/FilDOS/blob/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a/src/main/ai/llm/llmRuntime.ts), [file tools](https://github.com/ahmedfahim21/FilDOS/blob/aa575e8d43dccd5b7c731c8a61b26acf53c2d15a/src/main/ai/llm/tools.ts) |
